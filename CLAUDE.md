# PampGram — CLAUDE.md

## Что это за проект

Мод для официального [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS).
Хранит патчи и новые Swift-модули; форк собирается отдельно.

Основные фичи: локальные подарки, визуалы профиля (Stars/TON/рубли, уровни 1–100),
Ghost-режим (сохранение удалённых сообщений), экран пресетов и настроек PampGram.

## Структура

```
server/          — серверная часть (подписки, воркеры)
mod/             — модули мода
  components/    — Swift-компоненты (экраны, UI-блоки)
  apply-profile-visuals.py — скрипт применения визуалов профиля
  telegram-ios.patch       — патч на оригинальный репозиторий Telegram-iOS
```

## Как работать с Claude Code

### Что такое Claude Code

Claude Code — это ИИ-ассистент прямо в терминале (или в браузере на claude.ai/code).
Ты пишешь задачу обычным текстом, он читает код, вносит изменения, коммитит и пушит.

### Основные команды

| Что сделать | Как написать |
|---|---|
| Добавить фичу | «Добавь экран настроек Ghost-режима» |
| Исправить баг | «В файле X падает при Y, почини» |
| Объяснить код | «Что делает этот файл?» |
| Сделать ревью | `/code-review` |
| Запустить проект | `/run` |

### Как это выглядит на практике

1. Открываешь чат с Claude Code (браузер или терминал `claude`)
2. Пишешь задачу по-русски или по-английски — как удобно
3. Claude читает нужные файлы, делает изменения
4. Сам коммитит и пушит на нужную ветку
5. Ты проверяешь результат

### Ветки

- Основная ветка разработки: `main` (или та, что указана в задаче)
- Для фич Claude создаёт ветки вида `claude/описание-задачи`

### Что писать Claude

Просто описывай задачу — не нужно знать структуру файлов или команды git.
Примеры:
- «Сделай так, чтобы баланс Stars отображался с иконкой ⭐»
- «Добавь возможность скрывать онлайн-статус от конкретных контактов»
- «Почини краш при открытии экрана коллекции подарков»

### Если что-то непонятно

Просто спроси: «Объясни что делает этот код» или «Как лучше реализовать X?»
Claude ответит и предложит варианты.
