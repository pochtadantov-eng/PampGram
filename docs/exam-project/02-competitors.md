# 2. Анализ аналогичных программных продуктов

Проанализировано пять модификаций мессенджера Telegram, ближайших по функциям
к PampGram. Для каждого — краткое описание, состав интерфейса главной / промо-
страницы (заменяет PrintScreen — реальные скриншоты приложены в pdf-версии
отчёта), достоинства и недостатки.

> В отчётной PDF-версии на этой странице размещён скриншот
> (`docs/exam-project/mockups/competitors/*.png`). В git хранится текстовое
> описание элементов интерфейса, чтобы отчёт можно было воспроизвести.

## 2.1. Nicegram

**Сайт:** https://nicegram.app

**Скриншот (описание элементов):** тёмный hero с логотипом и слоганом
«Nicegram — Telegram, but better», ниже — три большие карточки функций
(AI, Speech-to-text, Multi-account), скачивание из App Store, футер с
Privacy Policy.

### Достоинства
- Официально в App Store — нулевой порог установки.
- Встроенный AI-ассистент и распознавание речи в голосовых.
- Мультиаккаунт без ограничения на 3 профиля.
- Красивый сайт: hero + карточки функций + отзывы, всё flex-раскладкой.

### Недостатки
- Часть функций платные (подписка Nicegram Premium).
- Нет визуальных «подарков» и кастомизации профиля.
- Дизайн клиента почти не отличается от оригинального Telegram —
  кастомизаторам скучно.

## 2.2. Swiftgram

**Сайт:** https://swiftgram.app

**Скриншот (описание элементов):** светлый hero с крупным градиентным
заголовком, скриншоты приложения справа, ниже — таблица «feature vs
official Telegram», футер с ссылками на GitHub и Telegram-канал.

### Достоинства
- Полностью бесплатный и open-source.
- Много Ghost-функций (отключение прочтений, typing, автоскрытие онлайна).
- Хорошая интеграция с TestFlight — обновления приходят быстро.

### Недостатки
- Нет своей экосистемы подарков и визуальных балансов.
- Интерфейс сайта перегружен таблицей и мелким текстом.
- Отсутствует раздел «как установить» для не-джейлбрейк пользователей.

## 2.3. Telegram X (официальный от Telegram)

**Сайт:** https://telegram.org/apps

**Скриншот (описание элементов):** страница App Store: скриншоты вертикальной
галереей, описание версии, кнопка «Загрузить». Отдельного лендинга нет.

### Достоинства
- Официальная сборка от Telegram — доверие максимальное.
- Отличная производительность и анимации (свой рендер-движок).
- Единый аккаунт с обычным Telegram.

### Недостатки
- Нет никакой кастомизации сверх официальной.
- Нет Ghost-функций.
- Продвигается через App Store, полноценного сайта продукта нет —
  сложно сформировать бренд.

## 2.4. MaterialGram (Android-аналог)

**Сайт:** https://materialgram.app

**Скриншот (описание элементов):** hero в Material You стиле с большим
скриншотом телефона, ниже — сетка карточек «What's inside» 3×2,
блок «Get it on GitHub», FAQ, футер.

### Достоинства
- Ярко выраженный дизайн-язык Material You.
- Прозрачная story: changelog + описание изменений к каждому релизу.
- Активное коммьюнити на GitHub Discussions.

### Недостатки
- Только Android — вся iOS-аудитория недоступна.
- Нет визуальных подарков / рейтинга профиля.
- Установка через APK пугает часть пользователей.

---

## 2.5. Ayugram

**Сайт:** https://ayugram.one

**Скриншот (описание элементов):** тёмно-фиолетовый hero, слева — тезисы
про «anti-recall» и Ghost, справа — статичный скриншот приложения,
далее — блок «Features» списком с иконками, footer с donate-кнопками.

### Достоинства
- Мощные Ghost-функции: anti-recall (сохранение удалённых), скрытый
  просмотр историй, скрытые реакции.
- Понятная структура сайта, легко найти любую функцию.
- Открытый исходный код и криптодонаты.

### Недостатки
- Ориентация на Windows/Linux/Android — на iOS сборка нестабильна.
- Нет системы подарков и «декоративных» функций для молодой аудитории.
- Дизайн сайта аскетичный, ЦА 16–24 воспринимает как «инженерный».

## Выводы для собственного интерфейса

1. **Ниша PampGram на рынке пустая:** ни один из аналогов не даёт связки
   «визуальные подарки + Ghost + iOS-кастомизация». Позиционирование
   сайта должно бить именно по этой уникальности.
2. **Дизайн Nicegram** — эталон подачи (hero → карточки → CTA).
   Заимствуем структуру, но добавляем блок «Каталог подарков»,
   которого нет ни у кого.
3. **Ошибка Swiftgram и Ayugram** — перегруженные страницы. Наш сайт
   должен быть построен на flex-контейнерах с воздухом, шрифт крупный.
4. **Ошибка Telegram X** — нет отдельного сайта. У PampGram обязательно
   должен быть лендинг с брендом и SEO, а не только страница релиза
   на GitHub.
5. **Ошибка MaterialGram и Ayugram** — нет пошагового «как установить».
   Мы делаем таблицу шагов и форму подписки на релизы.
6. **Тёмная тема, градиенты, Glass-эффекты** — соответствует iOS 17+ и
   ожиданиям молодой ЦА, отстраивает от «инженерных» Ayugram/Swiftgram.
