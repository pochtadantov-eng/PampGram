# 4. Макет интерфейса (high-fidelity)

Полноценный макет интерфейса реализован **сразу в вёрстке**: файл
`site/index.html` открывается в браузере и является одновременно
макетом и рабочей интернет-страницей. Такой подход выбран потому,
что live-макет:

- позволяет проверить адаптив на реальном устройстве,
- переносится в PDF одним нажатием (Cmd/Ctrl + P → PDF),
- гарантирует пиксель-в-пиксель совпадение макета и релиза.

## Цвета

| Токен | Hex | Применение |
| --- | --- | --- |
| `--bg` | `#0b0d17` | основной фон (тёмная тема) |
| `--surface` | `#151a2c` | карточки, поля ввода |
| `--surface-2` | `#1b2136` | вложенные поверхности, полосы таблицы |
| `--brand` | `#7b5bff` | акцент, начало градиента |
| `--brand-2` | `#22c1ff` | акцент, середина градиента |
| `--brand-3` | `#ff5bd2` | акцент, «розовая искра» подарков |
| `--success` | `#3ddc84` | ok-статусы формы |
| `--danger` | `#ff5b6f` | ошибки формы |
| `--text` | `#eef1ff` | основной текст |
| `--text-mut` | `#a9b0d0` | вторичный текст |

Дополнительно поддержана **светлая тема** — переопределены токены под
`@media (prefers-color-scheme: light)` и вручную через
`data-theme="light"` на `:root`.

## Типографика

- Шрифт: **Manrope** (400/500/600/700/800), Google Fonts, с преконнектом.
- Заголовки — clamp() для плавной адаптивной шкалы: h1
  `clamp(34px, 5.4vw, 60px)`, h2 `clamp(26px, 4vw, 42px)`.
- Основной текст: 15–16 px, `line-height: 1.55`.

## Компоненты
- **Кнопки** трёх видов: `.btn--primary` (градиент), `.btn--ghost`
  (обводка), `.btn--sm` (компактная).
- **Chip** — универсальный элемент: используется в подсказке hero, в
  фильтре каталога и в чекбоксах формы.
- **Карточка каталога** — единая ширина миниатюры, tag сверху,
  название, описание и мета-строка (рейтинг + версия появления).
- **Форма** с валидацией: name, email, select, чекбоксы `topics[]`,
  чекбокс согласия. Статус отправки сообщается через
  `role="status" aria-live="polite"`.
- **Details/summary** — используется для FAQ, работает без JS.

## Отдельные экраны (desktop / tablet / mobile)

Все три экрана — это один и тот же `index.html`, отрендеренный в
DevTools Chrome / Safari на breakpoints:

| Устройство | Ширина | Как проверять |
| --- | --- | --- |
| Стационарный ПК | 1440 × 900 | обычный десктоп-режим |
| Планшет | 820 × 1180 (iPad Air) | DevTools · Device mode · iPad Air |
| Мобильное устройство | 393 × 852 (iPhone 15) | DevTools · Device mode · iPhone 15 |

Для отчётной PDF макеты по каждому breakpoint сохраняются как
`mockups/desktop.pdf`, `mockups/tablet.pdf`, `mockups/mobile.pdf`
через «Печать → Сохранить в PDF» (эмуляция устройства в DevTools).
