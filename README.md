# PampGram

Мод для официального [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS)
(форк собирается отдельно, здесь хранятся патчи и новые модули).

## Функции

- [`mod/phantom-gift`](mod/phantom-gift/README.md) — вкладка «Фантом» в экране отправки
  подарков: визуальная, явно помеченная как ненастоящая передача подарка (без списания Stars).
