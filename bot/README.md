# PampGram Bot — управление аккаунтом через бота

Телеграм-бот, который подключается к вашему аккаунту через официальный
**Telegram Business** и позволяет управлять им из чата с ботом с любого устройства:

- 🎁 просмотр подарков аккаунта (постранично, с деталями: модель, узор, фон, цена передачи);
- 📤 передача уникальных (NFT) подарков другому пользователю;
- ✨ улучшение обычных подарков до уникальных;
- 💱 продажа (конвертация) подарков в звёзды;
- ⭐ баланс звёзд аккаунта;
- ✉️ отправка сообщений от имени аккаунта и ответы на входящие (`FORWARD_MESSAGES=1`);
- 👤 смена имени и био.

Сессия аккаунта, пароль и коды входа боту **не передаются**: доступ ограничен правами,
которые вы сами выдаёте в настройках Telegram Business и можете отозвать в любой момент.
Подключения от аккаунтов, которых нет в `OWNER_IDS`, бот игнорирует.

## Требования

- Telegram Premium на управляемом аккаунте (без него нет раздела «Telegram Business»).
- Python 3.10+.

## Запуск

```bash
cd bot
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN и свой OWNER_IDS
python -m pampbot
```

Свой Telegram ID можно узнать, например, у @userinfobot.

## Подключение аккаунта

1. @BotFather → ваш бот → *Bot Settings → Business Mode → Turn on*.
2. В Telegram: *Настройки → Telegram Business → Чат-боты* → введите юзернейм бота.
3. Включите права: «Просмотр подарков и звёзд», «Передача и улучшение подарков»,
   «Конвертация подарков в звёзды», «Передача звёзд» (платные передачи и улучшения
   оплачиваются с баланса аккаунта), а также ответы на сообщения и редактирование профиля при желании.
4. Бот пришлёт «✅ Аккаунт подключён» — откройте /menu.

## Ограничения Telegram

- Передать подарок или написать можно только тем, кто писал аккаунту за последние 24 часа.
- У уникальных подарков бывает задержка до следующей передачи и плата в звёздах — бот показывает обе.
- Все необратимые действия (передача, продажа, улучшение) требуют подтверждения.
