# PampWallet

Отдельное iOS-приложение, в стиле TonKeeper: LARP-кошелёк с двумя локальными балансами TON,
между которыми можно «отправлять» и «получать» переводы. Никак не связано с модом в `mod/`
— свой Xcode-проект, свой workflow, свой .ipa.

## Что это и чего это не делает

- Два локальных кошелька («Кошелёк 1», «Кошелёк 2»), каждый — просто число, которое хранит
  само приложение (`UserDefaults`, обычный JSON). Никакого реального TON-кошелька, seed-фразы
  или приватного ключа в приложении нет и никогда не было.
- «Отправить» переводит баланс только между этими двумя локальными кошельками внутри
  приложения. Получатель не выбирается — он всего один, второй кошелёк.
- Приложение не делает вообще ни одного сетевого запроса. Всё, что оно показывает,
  придумано и хранится на устройстве.
- Адрес каждого кошелька (`generatePhantomTonAddress` в `Sources/Models/Wallet.swift`)
  выглядит как настоящий user-friendly TON-адрес — тот же формат, тот же префикс «UQ», —
  но его последние 2 байта не настоящая чек-сумма (CRC16), а случайные. Любой настоящий
  TON-кошелёк проверяет эту чек-сумму перед отправкой, значит по этому адресу физически
  нельзя провести настоящий перевод, даже если кто-то попробует. Это сделано специально,
  чтобы приложение оставалось флекс-игрушкой, а не чем-то, чем можно обмануть человека в
  реальной сделке.

## Сборка

Мак не нужен — так же, как и для мода. Вкладка **Actions** → workflow **Build PampWallet
(unsigned IPA)** → **Run workflow**. Пара минут, готовый `PampWallet.ipa` — в артефакте
**PampWallet-ipa** внизу прогона.

`.ipa` полностью **без подписи** (в `project.yml` явно выключен code signing — здесь нет
и не может быть настоящего сертификата разработчика). Это ожидаемо: ставить нужно через
**Sideloadly** или **AltStore** — они подписывают файл вашим Apple ID при установке, тот же
способ, что уже описан для мода в `mod/README.md`.

Собрать локально на Mac тоже можно:

```sh
cd wallet-app
brew install xcodegen
xcodegen generate
open PampWallet.xcodeproj
```

## Структура

```
wallet-app/
  project.yml            — описание Xcode-проекта для XcodeGen (генерирует .xcodeproj)
  Info.plist
  Sources/
    PampWalletApp.swift  — точка входа
    Models/
      Wallet.swift        — модели кошелька/операции + генератор косметического адреса
      WalletStore.swift    — локальное хранилище (UserDefaults), send/topUp
      Formatting.swift     — форматирование TON-сумм
    Views/
      WalletHomeView.swift  — главный экран: баланс, переключатель кошельков, активность
      SendView.swift         — отправить
      ReceiveView.swift      — получить (адрес + QR)
```

Иконка приложения пока не добавлена (будет системная заглушка) — это чисто косметическая
доработка на потом, на сборку не влияет.
