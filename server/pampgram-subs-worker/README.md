# pampgram-subs — бэкенд для админ-панели

Единственная часть PampGram, у которой есть сервер. Хранит одну вещь: тариф
(`pro`/`standard`) на Telegram-аккаунт. Всё остальное в моде как было — только
локально на устройстве.

## Разворачивание (один раз)

Нужен бесплатный аккаунт на [Cloudflare](https://dash.cloudflare.com/sign-up) —
хостинг воркера и KV бесплатны в пределах щедрого лимита (100k запросов/день).
Нужен установленный [Node.js](https://nodejs.org) (даёт команду `npm`).

### Проще всего — один скрипт

```sh
git clone https://github.com/pochtadantov-eng/PampGram.git
cd PampGram
git checkout claude/telegram-iphone-mod-r8k06v
cd server/pampgram-subs-worker
bash deploy.sh
```

Скрипт сам поставит wrangler, попросит войти в Cloudflare (откроется браузер —
нажать «Allow»), создаст хранилище, впишет его id в `wrangler.toml`,
сгенерирует `ADMIN_TOKEN` и сразу настроит его на сервере, задеплоит и в конце
выведет два значения:

- **адрес сервера** — его нужно прислать в чат Claude, чтобы он вписал его в
  код и собрал новую версию;
- **ADMIN_TOKEN** — его никуда пересылать не нужно, он вводится один раз прямо
  в приложении (см. ниже).

### Вручную, шаг за шагом

Если скрипт по какой-то причине не подходит:

```sh
cd server/pampgram-subs-worker
npm install -g wrangler   # если ещё не стоит
wrangler login             # откроет браузер для входа в Cloudflare

# 1. Создать KV-хранилище
wrangler kv namespace create SUBS
# Команда выведет что-то вроде:
#   kv_namespaces = [ { binding = "SUBS", id = "abcd1234..." } ]
# Скопируй id и вставь в wrangler.toml вместо REPLACE_WITH_KV_NAMESPACE_ID

# 2. Сгенерировать свой секретный админ-токен и сразу задать его на сервере —
#    сам токен нигде в репозитории не хранится и не должен там оказаться:
openssl rand -hex 32
# Скопируй то, что вывелось, и вставь при запросе:
wrangler secret put ADMIN_TOKEN

# 3. Задеплоить
wrangler deploy
```

После `wrangler deploy` в терминале появится адрес воркера — что-то вроде

```
https://pampgram-subs.<твой-поддомен>.workers.dev
```

Этот адрес нужно прислать в чат Claude — он вставит его в
`mod/components/PampGramCore/Sources/PampGramSubscriptionAPI.swift`
(константа `baseURL`) вместо плейсхолдера и запушит; без этого приложение
будет стучаться в несуществующий адрес. Сам токен присылать не нужно — он
задаётся прямо в приложении, см. ниже.

## Подпись ответов (RESPONSE_SIGNING_KEY)

`/status`, `/ban-status` и `/min-version` подписывают свой ответ отдельным секретом —
так приложение отличает настоящий ответ сервера от подделанного прокси на телефоне
пользователя (подробности в комментариях `hmacSign` в `src/index.js`). Это отдельный
секрет, не `ADMIN_TOKEN`, и значение уже зашито в
`PampGramSubscriptionAPI.swift` (константа `responseSigningKey`) — на сервере его
нужно задать **тем же самым** значением:

```sh
wrangler secret put RESPONSE_SIGNING_KEY
# на запрос значения вставить именно то, что сейчас стоит в responseSigningKey
# в PampGramSubscriptionAPI.swift — не генерировать новое
```

Если это не сделать (или вставить другое значение) — проверка подписи будет
проваливаться всегда, и приложение будет показывать STANDARD даже тем, кому
реально выдан PRO, пока секрет не совпадёт.

## Как ввести токен в приложении

Токен из шага 2 нигде в коде не хранится — его нужно один раз ввести прямо в
приложении, на аккаунте админа: **PampGram → Админ-панель → Админ-токен**.
Он сохранится только на этом устройстве (в локальном Postbox) и будет
подставляться в каждый запрос на выдачу подписки.

## Проверка

```sh
curl "https://pampgram-subs.<поддомен>.workers.dev/status?id=123"
# {"tier":"standard"}

curl -X POST "https://pampgram-subs.<поддомен>.workers.dev/grant" \
  -H "content-type: application/json" \
  -d '{"id":123,"tier":"pro","token":"<твой ADMIN_TOKEN>"}'
# {"ok":true}

curl "https://pampgram-subs.<поддомен>.workers.dev/status?id=123"
# {"tier":"pro"}
```

## Ключи активации (при продаже файла)

`/grant` выше требует, чтобы ты уже знал Telegram-аккаунт человека — годится, когда выдаёшь
подписку вручную. При продаже самого файла мода это не работает: покупатель может переслать
файл кому угодно бесплатно, и без привязки к конкретному аккаунту ничего этому не мешает.

Ключ решает это иначе: генерируется один раз, активирует **все** функции мода, но только на том
Telegram-аккаунте, который первым его введёт. Экран «Введи ключ» появляется у каждого, кто ещё
не активировал мод — сгенерировать ключ и переслать его покупателю можно прямо в приложении:
**PampGram → Админ-панель → Ключи активации → Сгенерировать ключ** (копируется в буфer
автоматически). Дальше это уже не про сервер — как передать ключ покупателю (в переписке, при
продаже) решаешь сам.

```sh
curl -X POST "https://pampgram-subs.<поддомен>.workers.dev/keys/generate" \
  -H "content-type: application/json" \
  -d '{"token":"<твой ADMIN_TOKEN>","tier":"standard"}'
# {"key":"PMP-XXXXX-XXXXX-XXXXX-XXXXX","tier":"standard"}

curl -X POST "https://pampgram-subs.<поддомен>.workers.dev/keys/redeem" \
  -H "content-type: application/json" \
  -d '{"key":"PMP-XXXXX-XXXXX-XXXXX-XXXXX","id":123}'
# {"ok":true,"tier":"standard"}

# Тот же ключ с другого id — уже не сработает:
curl -X POST "https://pampgram-subs.<поддомен>.workers.dev/keys/redeem" \
  -H "content-type: application/json" \
  -d '{"key":"PMP-XXXXX-XXXXX-XXXXX-XXXXX","id":456}'
# {"error":"already used"}
```

Твой собственный админ-аккаунт активируется автоматически при первом открытии вкладки PampGram
— ключ для себя вводить не нужно.

## Важно про токен

`ADMIN_TOKEN` существует в двух местах: как секрет Cloudflare (`wrangler
secret put`, никогда не в файлах репозитория) и локально на устройстве
админа (введён через экран «Админ-панель», тоже никогда не в репозитории).
Экран админки в самом приложении показывается только аккаунту с id
`8557314630` — это ограничивает, кто *увидит* кнопку, но не является
криптографической защитой самого токена: если у кого-то окажется и
модифицированная копия приложения с этим экраном разблокированным, и
значение токена — он сможет им воспользоваться. Для хобби-мода это
приемлемый компромисс; если понадобится более серьёзная защита, следующий шаг —
привязать выдачу токена к реальной Telegram-авторизации (Login Widget или бот
с подтверждением), но это отдельная, более объёмная задача.

## Бот (автовыдача, тарифы, база пользователей)

Бот живёт в этом же Worker (`POST /tg`), данные — в том же KV. Код: `src/bot/`.

### Запуск

1. В Telegram у @BotFather: `/newbot` → получить токен.
2. Один раз залогиниться: `npx wrangler login`.
3. Из этой папки: `BOT_TOKEN='123:ABC...' bash setup-bot.sh` — скрипт сохранит секреты (`BOT_TOKEN`, `WEBHOOK_SECRET`), задеплоит Worker и поставит webhook.
4. Открыть бота и написать `/admin` с аккаунта из `ADMIN_TG_IDS` (`wrangler.toml`).

**Не запускай `deploy.sh` повторно** на уже настроенном Worker — он создаёт новое KV-хранилище и затрёт связку.

### Что умеет

- **Покупатель:** `/start` → «Магазин» → оплата Telegram Stars (⭐, XTR, без платёжного провайдера) → после оплаты бот сам присылает набор (файлы IPA/сертификат, ссылки, текст) и ключ активации нужного тарифа (Standard → Premium, есть апгрейд).
- **Админ (`/admin`):** тарифы (цена, срок, уровень), комплект выдачи (загрузка файлов прямо в бота — выдаются по `file_id`), список пользователей с фильтрами, профиль (ник, версия приложения, последние заходы, покупки), бан/разбан, ручная выдача тарифа, заметка, «вызвать на проверку в ЛС» (пользователю приходит сообщение с кнопкой, неотвеченный запрос истекает по cron каждые 10 минут).
- Stars выводятся в Telegram через Fragment / в настройках бота.

### Способы оплаты и реквизиты

`/admin` → **💳 Оплата**. Встроенный способ — Telegram Stars (его можно выключить, удалить нельзя). Сколько угодно своих способов: карта, СБП, кошельки USDT/TON/BTC, любой текст.

- **Добавить:** название → реквизиты (текст в несколько строк; строки вида `Карта: 2202 …` покупатель копирует одним тапом) → курс, то есть цена за 1 ⭐ в вашей валюте, например `1.8 ₽` или `0.02 USDT`. Цена тарифа = цена в ⭐ × курс, округляется вверх до копеек.
- **Править:** название, реквизиты, курс, включить/выключить, удалить — в карточке способа.
- **Как проходит покупка:** покупатель выбирает тариф → способ → видит реквизиты и точную сумму → жмёт «Я оплатил(а)» и может прислать скриншот. Вам приходит заявка с кнопками **✅ Подтвердить / ❌ Отклонить** (скриншоты копируются вам с теми же кнопками). Ключ и файлы уходят только после вашего подтверждения. Очередь заявок: `/admin` → «🧾 Заявки на оплату».
- Бот **не может проверить** перевод сам: подтверждение — ваше решение. Выручка в статистике считается отдельно по каждой валюте.

### Внешний вид бота: баннеры и анимированные эмодзи

- **🖼 Баннеры** (`/admin` → «Баннеры»): картинка, GIF или видео над главным меню и над списком тарифов. Загружаются прямо в бота, убрать или заменить можно там же. Лучше горизонтальная картинка около 1280×720. Если Telegram откажет в файле, бот покажет обычный текст.
- **✨ Эмодзи** (`/admin` → «Эмодзи»): для каждого обычного эмодзи из списка (⭐ 🛒 🔑 …) можно назначить анимированный: нажмите на него и пришлите боту анимированный эмодзи (можно сразу несколько, они встанут по порядку). Анимация появляется и в тексте, и на кнопках.
  - Telegram разрешает это только если у владельца бота есть **Telegram Premium** (или у бота куплено имя на Fragment). Без этого бот продолжает работать с обычными эмодзи, а причина отказа видна на экране «Эмодзи». Кнопка «Проверить» присылает пробное сообщение.
- Тариф без срока показывается как «навсегда», даже если в названии осталось «0 дней».

### Свои кнопки, пароль и копии

- **🔘 Кнопки** (`/admin` → «Кнопки»): в разделах «Главное меню» и «Тарифы» можно добавить свою кнопку (ссылка или страница с текстом), назвать её, выбрать эмодзи (обычный или анимированный), скрыть, переставить. Встроенные кнопки меню тоже можно переименовать и сменить им эмодзи; «Вернуть стандартную» отменяет правки.
- **🔐 Пароль:** всё, что удаляет сделанное в панели (тариф, пункт выдачи, способ оплаты, баннер, свою кнопку, эмодзи, «Сбросить все», восстановление копии), спрашивает пароль. В хранилище лежит только соль и SHA-256, в коде и репозитории пароля нет. Сообщение с паролем бот сразу удаляет. 5 неверных попыток блокируют ввод на 10 минут. Сменить пароль: `/admin` → «Пароль». Пароль из 4 цифр короткий: защищает от случайного нажатия и чужого доступа к панели, но не от подбора при утечке хранилища.
- **💾 Копии:** перед каждым удалением бот сам делает копию всех настроек (общие настройки, тарифы, выдача, способы оплаты, эмодзи, баннеры, кнопки), хранятся 12 последних. Вернуть копию можно в «Копии» (нужен пароль).
- **Обновления не стирают настройки.** Всё хранится в KV (`cfg`, `tariffs`, `bundle`, `pay`, `emoji`, `banners`, `buttons`), а `deploy` меняет только код. Единственное исключение — переменные из `wrangler.toml` (`ADMIN_TG_IDS`): их править именно там.

### Телеметрия из приложения

Приложение шлёт в `/status` версию, билд, ник и имя (`v,b,u,n`). Маршрут публичный, поэтому эти поля **информативные и не подтверждены** — на доступ они не влияют.

### Тесты

`npm test` — 67 тестов на in-memory заглушках KV/Telegram (покупка, идемпотентность оплаты, ручные способы оплаты и подтверждение, баны, проверка в ЛС, редакторы, webhook).

### Ограничения

Нет интерфейса возвратов и рассылок; у Standard нет срока на сервере; реальное поведение Telegram/Cloudflare локально не проверялось.
